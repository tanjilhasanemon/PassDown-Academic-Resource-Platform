Request Table Setup
-------------------
The repository does not currently use a database migration tool. When updating
an existing PostgreSQL database, create the FR-10 table and indexes using:

.. code-block:: sql

   CREATE TABLE requests (
       id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
       course_id INTEGER NOT NULL REFERENCES courses(id),
       submitted_by INTEGER NOT NULL REFERENCES users(id),
       description TEXT NOT NULL,
       status VARCHAR(20) NOT NULL DEFAULT 'open',
       created_at TIMESTAMPTZ NOT NULL DEFAULT now()
   );
   CREATE INDEX ix_requests_course_id ON requests(course_id);
   CREATE INDEX ix_requests_submitted_by ON requests(submitted_by);
