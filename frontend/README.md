# PassDown Frontend (React 18 + TypeScript + Vite)

This directory contains the **PassDown** Single-Page Application (ECB Boundary Layer), implementing the **Swiss Academic Archive** editorial design system with full light and dark theme support (`[data-theme="light"]` / `[data-theme="dark"]`).

## Scripts

* `npm run dev` — Starts the Vite development server at `http://localhost:5173`.
* `npm run typecheck` — Runs `tsc --noEmit` in strict mode (`noUnusedLocals`, `noUnusedParameters`).
* `npm run build` — Builds the optimized production bundle into `dist/`.
* `npm run docs` — Generates TypeDoc HTML documentation into `../docs/frontend-docs`.
